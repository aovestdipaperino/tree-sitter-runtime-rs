# Map: port of the tree-sitter 0.26.13 runtime to Rust

Goal: the C runtime as a pure Rust crate exporting the same C ABI, verified equal to the C by a
whole-library differential harness (ADR-007). Reference C is in `src/` and `include/`, unmodified.

Decisions: [DECISIONS.md](DECISIONS.md) (ADR-001 to ADR-011). Terms: [GLOSSARY.md](GLOSSARY.md).
Measured state: `rust/PORT_MAP.md` (generated by `rust-anything map --write`).

## Units (from `rust-anything analyze --whole-app`)

State is `open`, `claimed by <session> <date>`, or `done`. Waves go lowest first (ADR-009 checkpoints
after each group).

## Out of scope
`src/wasm_store.c` and `src/wasm/` (ADR-003). Windows (ADR-009, later).

## Open questions
- ADR-011 (mixed build, one unit at a time) is the agent's proposal: confirm or veto.
- Which `tree-sitter` binding fork to patch in, and whether to keep upstream's `binding_rust` unchanged (ADR-008).
- Bitfield layout of `SubtreeInlineData`/`SubtreeHeapData` on big-endian targets: not supported initially.

## Checkpoints
1. After wave 0 and 1 (leaf modules) and the differential harness.
2. After the lexer and language, and the tangled core.
3. After node and cursor. 4. After queries.


Lift done by hand (see HANDOFF.md, "Lift"): the C reference is behind the `reference` feature; the shipped crate builds only `runtime/c/lexer_log.c`.
